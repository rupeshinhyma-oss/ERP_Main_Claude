Fields in Form (Quick Access & Add New both forms
Inquiry by (buyer company name) (default from login but editable) as for example, F&B, One Stop, Inhyma. But, admin. can choose the company for which this inquiry is generated. – to add this field in Quick Add Form.

Inquiry consignment code - as for example FB1, FB2, OS1, OS2 (these are for Uganda consignments for F&B and One Stop, then ING1, ING2 (for Inhyma India Gujarat), INM1, INM2 (for Inhyma Mumbai), INC1 (for Chennai), INI1 (for Indore) etc. (respective company users should see only relevant options to choose, but admin can see all) – Master to create and choose from dropdown menu – this field to add in Add New Main Inquiry form.

Product Name (to choose from dropdown menu from masters & keyword suggestions)
Quantity / UOM (UOM to reflect automatically as per inventory master of that item)
Brand Preference (description) – By Default should be prefilled as per last but editable.
Product Specs / Remarks – By Default should be prefilled as per last but editable.
Status - Proposed / Approved (by default Proposed)

Proposed / Approved Date and Proposed / Approved By (field not needed, but auto generated from user login). This will be separate for each item and seen when we go inside company list.
Tally Entry Posted ? (to show pending by default in inquiry (consignment) list for each item separately and then some easy way to select and change multiple items to “Posted”. All pending entries to show on top by default. User can see only Approved Items (proposed or rejected items not seen)
Remarks (by Yinglima China Procurement Team) – To show in list column with “View” Eye Button and can be added or edited from “Action” Panel.



Columns in List (1ST Layer – company wise)
Select (Check Box)
Inquiry by (buyer company name) – Clickable to go inside and see all consignments of that company, then should be possible to edit.
Inquiry consignment code - for example FB1, FB2, OS1, ING1, INC1 etc – clickable to go inside and see all items of that consignment with details. Then to be possible to edit.
Status - Proposed / Fully Approved / Partial Approved (because in a consignment, we may have approved some items and some proposed (pending to be approved)
Total CBM of that consignment (including approved and proposed items)
Total Weight of that consignment (including approved and proposed items)
Consignment Proposed / Approved Date and Proposed / Approved By 
Action – View Details, Edit, Delete.

Clarification
For Inquiry List (Display Summary), there will be 2 layers in this. 1st layer summary is company wise (for example, F&B, One Stop, Inhyma etc) and then once we click company, goes to 2nd layer and again summary list, Top filters, Actions etc. will appear for that particular consignment code of that company (for example, FB1, OS1, INM1, INM2).
